# Privacy Policy for Branch Chat (Gemini)

Last updated: October 25, 2026

Branch Chat creates focused Gemini side chats from text selected in a ChatGPT conversation.

## Data processed

The extension may process selected text, recent text from the open ChatGPT conversation, branch prompts and responses, associated images when available, a user-supplied Gemini API key, and locally saved branch records.

## Use and sharing

This information is used only to provide the branch response requested by the user. When the user sends a branch message, the relevant data and API key are sent over HTTPS to the Google Gemini API at `generativelanguage.googleapis.com`. Google's handling is governed by the terms and policies applicable to the user's Gemini API account. The extension does not transmit this data to the extension developer or sell it.

## Local storage and deletion

The API key and branch records are stored in `chrome.storage.local` in the user's Chrome profile. Users can delete individual branches, clear extension storage, or remove the extension.

## Security

Users should keep Gemini API keys private and should never commit them to source control or display them in screenshots.

## Contact

For privacy questions, open an issue in this repository without including API keys or private conversation content.
